# 09 — Environment Variables and Configuration

## Environment Variables

The tool reads all credentials and connection details from environment variables — never from code (except for `main_example.py` which is a legacy exception, see issue below).

### Required Variables

| Variable | Used By | What It Is |
|----------|---------|------------|
| `SOURCE_HOST` | `database_connectors.py`, `sql_extractor/postgres_extractor.py` | PostgreSQL server hostname or IP |
| `SOURCE_PORT` | same | PostgreSQL port (default: 5432) |
| `SOURCE_DATABASE` | same | PostgreSQL database name |
| `SOURCE_USERNAME` | same | PostgreSQL username |
| `SOURCE_PASSWORD` | same | PostgreSQL password |
| `SNOWFLAKE_ACCOUNT` | `database_connectors.py`, `sql_extractor/snowflake_extractor.py` | Snowflake account identifier (e.g., `ZJAUJWQ-EP12783`) |
| `SNOWFLAKE_DATABASE` | same | Snowflake database name |
| `SNOWFLAKE_SCHEMA` | same | Snowflake schema name |
| `SNOWFLAKE_USERNAME` | same | Snowflake username |
| `SNOWFLAKE_PASSWORD` | same | Snowflake password |
| `DIAL_API_KEY` | `ai_transformation/ai_rule_mapper.py`, `ai/rule_planner.py`, `model_probe.py` | EPAM DIAL API key |

### Optional Variables

| Variable | Default | What It Is |
|----------|---------|------------|
| `SOURCE_SCHEMA` | `public` | PostgreSQL schema (defaults to public) |
| `DIAL_API_BASE` | `https://ai-proxy.lab.epam.com` | DIAL endpoint URL |
| `DIAL_MODEL` | `gpt-4o` | Default AI model ID if not selected interactively |

## .env File Setup

Create a `.env` file in the project root (not committed to git):

```env
# PostgreSQL Source
SOURCE_HOST=your-postgres-host.example.com
SOURCE_PORT=5432
SOURCE_DATABASE=fms
SOURCE_USERNAME=your_pg_user
SOURCE_PASSWORD=your_pg_password
SOURCE_SCHEMA=public

# Snowflake Target
SNOWFLAKE_ACCOUNT=ZJAUJWQ-EP12783
SNOWFLAKE_DATABASE=storedge_fms_public
SNOWFLAKE_SCHEMA=public
SNOWFLAKE_USERNAME=your_sf_user
SNOWFLAKE_PASSWORD=your_sf_password

# EPAM DIAL AI
DIAL_API_KEY=your_dial_api_key_here
DIAL_API_BASE=https://ai-proxy.lab.epam.com
DIAL_MODEL=gpt-4o
```

The tool loads `.env` automatically via `python-dotenv`.

## rules_catalog.json

**Path:** `src/rules_catalog.json`
**Version:** 3.0
**Purpose:** Machine-readable source of truth for all validation rules.

Structure:
```json
{
  "version": "3.0",
  "rules": [ ... 13 rule objects ... ],
  "chaining_order": [ ... ordered list of rule IDs ... ],
  "rule_application_order": [ ... ]
}
```

Each rule object has:
- `id`: unique rule identifier (used in AI prompts and plan objects)
- `display_name`: human-readable name
- `description`: what the rule does
- `trigger_type_pairs`: list of `{source_type, target_type}` pairs that auto-trigger this rule
- `pg_sql_template`: SQL expression for PostgreSQL (with `{col}` placeholder)
- `sf_sql_template`: SQL expression for Snowflake (with `{col}` placeholder)
- `auto_detect`: `true` if the rule applies automatically when types match

**Do not edit this file directly.** It is read at startup and used to populate the `RuleRegistry`.

## rule_book_learned.json

**Path:** `src/rule_book_learned.json`
**Purpose:** Stores user-added custom rules and human corrections.

Written by:
- `validate_cli.py add-rule` command (interactive wizard)
- `learning/feedback.py FeedbackRecorder.record()` (automatic after human correction)

Current content (one test entry):
```json
{
  "version": "1.0",
  "last_updated": "2026-08-10",
  "learned_rules": [
    {
      "id": "ex_strip",
      "display_name": "example_Strip",
      "description": "Example: check for negative amounts",
      "pg_sql_template": "{col}",
      "sf_sql_template": "{col}",
      "source_type": "*",
      "target_type": "*",
      "is_learned": true,
      "learned_at": "2026-08-10"
    }
  ]
}
```

The `{col}` identity templates mean this rule does nothing (no transformation). It was added as a test/example to verify the `add-rule` CLI command works.

## Model Cache File

**Path:** `src/../.dial_model_cache.json` (one level above `src/`)
**Purpose:** 24-hour cache of DIAL model probe results.

Format:
```json
{
  "timestamp": 1723315200.0,
  "results": {
    "gpt-4o": true,
    "gpt-4": true,
    "gpt-4o-mini": false,
    "anthropic.claude-3-5-sonnet": false,
    ...
  }
}
```

Cache expires after 86400 seconds (24 hours). Run `python -c "from model_probe import invalidate_cache; invalidate_cache()"` to clear it.

## Claude Code Settings (.claude/settings.local.json)

**Path:** `src/.claude/settings.local.json`
**Purpose:** Controls which Bash commands Claude Code is allowed to run automatically (without prompting for permission each time).

Current permissions granted:
```json
{
  "permissions": {
    "allow": [
      "Bash(pytest)",
      "Bash(pip install pytest)",
      "Bash(python -c *)"
    ]
  }
}
```

This means Claude Code can run pytest, install pytest, and run short Python one-liners without asking. Everything else requires explicit approval.

[2/6] Checking environment variables... ✅ PASS
